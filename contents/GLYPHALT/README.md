# GLYPHALT-16

キャラクターセル(文字/記号タイル)を使って画像を変換する、ブラウザだけで動くツールです。
入力画像を8x8pxのセルに分割し、各セルを「背景色 + 前景色 + グリフ(文字/記号)」の組み合わせで
近似することで、レトロなキャラクター表現の画像に変換します。ビルド不要、`index.html`を開くだけで動きます。

## 使い方

ES Modules(`<script type="module">`)を使っているため、`index.html`を`file://`で直接開くと
CORS制限で動作しません。プロジェクトルートで簡易HTTPサーバーを立てて開いてください。

```bash
python -m http.server 8000
```

ブラウザで `http://localhost:8000` にアクセスし、画像をドロップ(またはクリックして選択)→
必要ならパレット/グリフセット(A・B)/画像調整/分割精度を変更 → CONVERTで変換 → PNGダウンロードまたはXへ投稿、
という流れです。サイドバーは画像に被さるオーバーレイパネルになっていて、ヘッダー右上の「☰ MENU」ボタンで
表示/非表示を切り替えられます(非表示にすると出力画像をネイティブ解像度のまま確認できます)。

## ディレクトリ構成

```
index.html         全体のレイアウトとDOM要素
style.css           見た目のスタイル
Colors/             同梱パレット画像(各16色のPNG。palette.jsが読み込む)
Glyphs/             同梱グリフシート画像(8x8グリッドのPNG。glyph.jsが読み込む)
src/
  main.js           エントリーポイント。DOM操作・イベント配線をすべて担う
  ui.js             スライダー同期、ステータス表示、エラートーストなどの小さなUIヘルパー
  palette.js         パレット画像の読み込み・選択・スウォッチON/OFFの管理
  glyph.js           グリフシート画像の読み込み・ビットマスク化。GLYPH SET A/Bの2スロットを独立に
                      管理し、両スロットの有効グリフを1つの候補プールに合成する
  image-pipeline.js  画像調整(sobel/blur/sharpen/brightness/contrast/saturation/hue/negative)
  matching.js        1セルに最も近い(背景色, 前景色, グリフ)の組を探すマッチング処理
  convert.js         変換処理本体(スナップショット固定→画像調整→パディング→セル毎マッチング→描画)
```

## パレット/グリフの追加

- パレット画像(`Colors/`): 任意サイズのPNGでよく、読み込み時に横16pxへ縮小サンプリングして16色として取り込みます。
- グリフ画像(`Glyphs/`): 8x8pxのセルが敷き詰められたPNG。輝度127をしきい値に二値化してビットマスク化します。

それぞれ`src/palette.js`の`PALETTE_FILES`、`src/glyph.js`の`GLYPH_FILES`に追記すると選択肢に追加されます。
