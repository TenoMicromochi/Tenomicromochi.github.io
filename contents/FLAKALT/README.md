# FLAKALT

ブラウザで動く地対空射撃シミュレーター。EGA 16色・640x400 の DOS 風画面で、
ワイヤーフレームの紙飛行機を偏差射撃で撃ち落とす。

依存ライブラリなし。ES モジュールと WebAudio と Pointer Lock だけで動く。

サイトのローカル確認は SODENMIR のルートで:

```bash
py -m http.server 8791
```

→ http://localhost:8791/contents/FLAKALT/index.html
（`file://` で開くと `data/guns.json` の fetch がブロックされるのでサーバー経由で）

単体版（プロトタイプ）は `Sandbox/Flakalt/`。倍率ボタンの画像パスとページの
外枠だけが違う。弾道や描画のコードは同じものを保つこと。

## 操作

| 入力 | 動作 |
|---|---|
| マウス | 砲の旋回・俯仰 |
| 左ボタン / Space | 発砲 |
| 右ボタン / Z | 望遠照準 |
| 1 / 2 / 3 / 4 / ホイール | 兵装選択 |
| R | 装填 |
| Tab | 目標の切り替え |
| P | ポーズ |
| M | ミュート |

画面外の `ORIGINAL(x1) / x2 / x3` ボタンで表示倍率を切り替えられる。
倍率は実機ピクセルで数えているので、DPR が 1 でない環境でも本当の整数倍になる。

## モード選択（出撃前）

| | 見越し点の表示 |
|---|---|
| EASY | 画面内に捉えている指定目標が 2000m 以内なら表示する |
| HARD | 一切表示しない（計器盤の TOF とリード量だけが頼り） |

EASY の表示は `✈ - - - - □`。目標の枠から破線が伸びて、その先の四角が
「そこへ撃て」という点。四角に照準環の中心を重ねて撃てば当たる。

進行方向の矢印は EASY / HARD どちらでも出る（向きだけで、速度は教えない）。
遠距離だと機体が数ドットになって機首の向きが読めなくなるため。

## 兵装

| | 7.7mm 4連装 | 12.7mm 2連装 | 20mm 機関砲 | 88mm 高射砲 |
|---|---|---|---|---|
| 初速 | 744 m/s | 887 m/s | 820 m/s | 820 m/s |
| 発射速度 | 2400 発/分 | 1120 発/分 | 480 発/分 | **15 発/分（4秒に1発）** |
| 旋回速度 | 62 °/s | 46 °/s | 30 °/s | 14 °/s |
| 弾種 | 通常弾 | 通常弾 | 榴弾（自爆 5.5s） | 時限信管榴弾（炸裂半径 26m） |
| 装弾数 / 再装填 | 240 / 3.2s | 200 / 4.2s | 60 / 5.4s | 12 / 9.0s |

口径が上がるほど威力は増すが、砲架が重くなって旋回が遅くなる。
20mm は突っ込んでくる機体には追従できない。早めに置いて待つしかない。

### 88mm の時限信管

指定目標への弾着時間がそのまま信管秒時になる（計器盤に `FUZE` と `BURST` として出る）。
つまり**信管は正しい距離で炸裂するが、炸裂する場所は砲身の向いた先**。
方位と仰角は自分で当てる必要がある。目標を指定していないと信管が設定されず、
`FUZE UNSET` と出て炸裂しない弾になる。

機械式信管なので秒時に 1.2% の誤差が乗る。4000m（飛翔 6.4 秒）だと
これだけで 30m ほど散る。史実どおり、当たらないのが普通の砲。

## 弾道について

弾は瞬間的には届かない。運動方程式は

```
dv/dt = -k * rho(h) * |v| * v  -  g        k = 0.5 * Cd * A / m
```

の二乗抗力で、空気密度は `rho(h) = exp(-h/8500)` の指数大気。
`data/guns.json` の口径・弾丸質量・抗力係数からそのまま `k` が決まる。

この式が出す弾速の距離減衰は実測値とほぼ一致する:

| | 300m | 500m | 1000m |
|---|---|---|---|
| 7.7mm (.303 相当) | 593 m/s | 509 m/s | 349 m/s |
| 12.7mm (.50 相当) | 762 m/s | 688 m/s | 534 m/s |
| 20mm | 716 m/s | 654 m/s | 522 m/s |
| 88mm | 791 m/s | 773 m/s | 728 m/s |

88mm だけ弾が重い（9.4kg）ので速度がほとんど落ちない。4000m でもまだ 510 m/s
出ていて、弾着まで 6.3 秒。他の砲が 2000m で息切れするのに対し、
この砲だけが遠距離の的に届く。

つまり必要なリード量も実物どおりになる。1000m の目標に 12.7mm を当てるには
弾着まで約 1.5 秒。秒速 90m で横切る機体なら 130m 以上先に撃つ必要がある。

計器盤の TOF（弾着時間）と LEAD（必要リード量）は、この抗力モデルを反転させた
解析解を反復して出している。照準環の目盛りはミル（mrad）で、焦点距離から逆算して
描いているので望遠にすると環も一緒に拡大する。つまり画面の目盛りは常に実角度と一致する。

落下量は真空の `0.5*g*t²` ではなく、鉛直方向にも抗力が効く前提の
`(g/c)(t - (1-e^{-ct})/c)`（`c = k*rho*v̄`）を使っている。
これを入れないと 7.7mm で 1200m 先を撃つと 8m 以上上に外れる。

さらにこの解析解を**実弾道で検算して詰めている**（`refineIntercept`）。
解析解は重力で増えた鉛直速度ぶんの抗力増加を見ていないので、飛翔時間が
5 秒を超えると弾が手前に落ちる。4000m で 40m ほど。88mm の信管秒時は
この時間をそのまま使うので、そのままだと当たらない。
そこで出した方向へ実際に弾を飛ばし、最接近時のずれを照準点に足し戻す
（ニュートン法 1 ステップ相当を 2 回）。1 ステップ内は弾も目標も直線運動と
みなして最接近時刻を解析的に求めるので、ステップ幅による量子化も起きない。

検算後の実測（散布界と信管誤差を切って 1 発ずつ撃った命中距離）:

| | 600m | 1200m | 2000m | 3000m | 4000m |
|---|---|---|---|---|---|
| 12.7mm | 命中 | 命中 | 命中 | 命中 | 到達せず |
| 88mm | 命中 | 命中 | 命中 | 命中 | 命中 |

射撃解の計算は 30Hz に間引いてある（物理は 200Hz）。目標は滑らかに動くので
表示にも命中にも影響しない。

## 砲架の追従

既定では砲架に旋回速度の上限がある（オプションで DIRECT に切替可）。
マウスが動かすのは「指令方向」で、砲身はそこへ最大角速度で追いつこうとする。
灰色の十字が指令方向、照準環が実際の砲身の向き。ズレが 3°を超えると十字が赤くなる。

目標のリードに加えて砲架のリードも要る、というのがこのモードの狙い。

## 実装メモ

- **描画は canvas 2D API を使わない。** 線がアンチエイリアスされるため。
  ImageData を直接叩いて Bresenham で 1px の線を引き、文字も同じ
  フレームバッファに打つ。3D の線と HUD の文字が同じ画素グリッドに乗る。
- **表示は整数倍のみ**（最大 x4）。`image-rendering: pixelated`。
- **物理は 200Hz 固定ステップ。** 弾速 900m/s でも 1 ステップ 4.5m しか進まないので
  線分と球の判定で薄い機体を貫通しない。描画は rAF まかせ。
- **フォントは内蔵の 6x8 ビットマップ。** TenoText8x8 を使っていないのは、
  ここが DOM ではなくフレームバッファで、OTF を読むとラスタライズで
  補間が入るため。必要なら TenoText8x8 を 8px でオフスクリーンに焼いて
  2値化し、このフォントテーブルを差し替えられる。
- **16 色しかないのでグラデーションは全部ディザ。** 空は地平線からの距離で
  バンドを作り、境目を 4x4 の Bayer 行列で繋いでいる。
- 撃墜時の破片は機体メッシュの稜線をそのまま飛ばしている。破片用のモデルはない。

## 動作確認

`window.FLAKALT` にアプリのインスタンスが入っている。コンソールから
`FLAKALT.game` で状態を覗いたり、`FLAKALT.game.update(1/200)` で手動で進められる。
