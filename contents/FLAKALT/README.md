# FLAKALT

ブラウザで動く地対空射撃シミュレーター。EGA 16色・640x400 の DOS 風画面で、
ワイヤーフレームの紙飛行機を偏差射撃で撃ち落とす。
依存ライブラリなし。ES モジュールと WebAudio と Pointer Lock だけで動く。

単体版（プロトタイプ）は `Sandbox/Flakalt/`。倍率ボタンの画像パス・ページの外枠・
`fit()` の windowed 時のレイアウト計算（ページの段組みに合わせるかどうか）が違う。
それ以外の弾道・描画・フルスクリーンまわりのコードは同じものを保つこと。

## 操作

| 入力 | 動作 |
|---|---|
| マウス | 砲の旋回・俯仰 |
| 方向キー | 砲の旋回・俯仰（マウスと併用。OPTIONS の `MOUSE AIM` を切ると唯一の操作手段になる） |
| 左ボタン / Space | 発砲 |
| 右ボタン / Z | 望遠照準（押しているあいだ覗く） |
| ホイール / W / S | **望遠中は倍率の変更**（x2〜x8）。倍率は覚えたままになる |
| 1 / 2 / 3 / 4 / ホイール | 兵装選択（ホイールは**望遠していないときだけ**） |
| R | 装填 |
| Tab | レティクルに入れた機体をロック / 何もない空で押すと解除 |
| Q | 見越し点の表示 ON/OFF（EASY・FREE RANGE 時のみ） |
| P | ポーズ |
| M | ミュート |
| F | フルスクリーンの切り替え |

画面外の `ORIGINAL(x1) / x2 / x3` ボタンで表示倍率を切り替えられる。
倍率は実機ピクセルで数えているので、DPR が 1 でない環境でも本当の整数倍になる。

## フルスクリーン

`⛶ FULLSCREEN` ボタン（画面外）・F キー・ゲーム内 OPTIONS の `FULLSCREEN` 項目、
どこからでも切り替えられる。フルスクリーンにしているのは `#stage`（キャンバス+
CRTフィルタ）だけで、ページ全体ではない。狙いは「フルスクリーンにした瞬間、
実画面に収まる最大の整数倍を自動で選ぶ」こと — たとえば 1600x900 のモニタなら
x2（1280x800）が自動で選ばれる。x1/x2/x3 ボタンでの手動指定はフルスクリーン中は
無視され、常に自動フィットになる（せっかくフルスクリーンにしたのに小さいままでは
意味がないため）。

x1/x2/x3 ボタンは `#stage` の外（兄弟要素）にあるため、フルスクリーン中は
ブラウザの仕様でそもそも描画されない（フルスクリーン要素の外は消える）。
「入る」のはボタンから、「出る」のは標準の Esc から、と割り切ってある。
ゲーム内 OPTIONS の項目はキャンバスの中の描画なので、フルスクリーン中も
消えずに使える（Esc を知らない人のための逃げ道）。

## CONTROLS & DOCTRINE（タイトル画面から）

操作の一覧と偏差射撃の解説。**2 ページ**に分かれていて、左右キーで
めくる。1 ページ目は操作キー全部と偏差射撃の基本（弾は瞬間的に届かない・
TOF とリードの読み方・GEARED 駆動のラグ・機体や見越し点が画面外に出たときの
表示）。2 ページ目は「THE THREAT」— 低空帯（DART / LANCE / WEDGE）と
高空帯（CRANE / CONDOR）の違い、PRISM、時限信管、国ごとの兵装差について。

以前は 1 ページに全部詰め込んでいて、実際には**画面の下端からはみ出して
表示が欠けていた**（キー一覧＋弾道解説の 4 段落だけで既に 388px、箱は
380px しかなかった）。敵機の種類・PRISM・画面外表示・見越し点の可変距離
といった後から足した仕様も一切載っていなかった。2 ページに割って、
1 ページ目は操作とその場で使う知識、2 ページ目は敵情報とルールという
形に整理してある。

## MISSION SETUP（出撃前）

START MISSION で開く。縦カーソルで 5 行を移動する。

```
EASY          説明
HARD          説明
FREE RANGE    説明
WEAPON SET    USA  JAPAN  GERMANY  BRITAIN  USSR
DIFFICULTY    ROOKIE  VETERAN  ACE
```

上 3 行が任務で、**カーソルを乗せた時点で選択が確定する**（1 つしか選べないため）。
下 2 行は左右キーで値を変える列。ENTER はどの行にいても出撃。
任務の行にカーソルが無いときは、選ばれている任務に `►` が付いたままになる。

DIFFICULTY はもともと OPTIONS にあったものを、出撃前に決めるものとしてここへ移した。
OPTIONS 側に残っているのは操作と表示の設定だけ。

任務は 3 つ。

| | 内容 | 見越し点 |
|---|---|---|
| EASY | 通常戦 | 画面内の指定目標が設定距離（既定 2.0km）以内なら表示 |
| HARD | 通常戦 | 一切表示しない（計器盤の TOF とリード量だけが頼り） |
| FREE RANGE | 練習・暇つぶし用 | EASY と同じ（Q で入切） |

EASY の表示は `✈ - - - - □`。目標の枠から破線が伸びて、その先の四角が
「そこへ撃て」という点。四角に照準環の中心を重ねて撃てば当たる。

**Q キーで見越し点を出したり消したりできる**（EASY / FREE RANGE 時のみ）。
補助ありで感覚を掴んでから切って試す、という往復ができるようにするためのもの。
HARD で Q を押しても効かない（そこを切り替えられると HARD の意味が消えるため、
「そもそも照準計算機を積んでいない」という扱いにしてある）。
いまの入切は計器盤の DROP の右に `Q:ON` / `Q:OFF` として出る。

進行方向の矢印は全モードで出る（向きだけで、速度は教えない）。
遠距離だと機体が数ドットになって機首の向きが読めなくなるため。

## FREE RANGE

攻撃してこない的を空に浮かべておくだけのモード。練習と暇つぶし用。

- 紙飛行機が **10 機**、旋回半径と高度をゆっくり変えながら漂う（近づいたり離れたり）
- **攻撃してこない**。陣地の耐久は減らず、ゲームオーバーも無い（上部バーは `POST ----`）
- 撃ち落とすと数秒後に静かに 1 機補充されて、常に 10 機を保つ
- **弾薬が尽きない**（予備弾数が毎フレーム満タンに戻る）。装填動作だけは残る
- ウェーブも得点ボーナスも無い。撃墜数と得点だけ数える

実装は既存の状態機械をそのまま使っている。`Aircraft` に `passive` を立てると
`maxRuns` が 0 になり、`ORBIT` から `ATTACK` へ遷移する条件（`runs < maxRuns`）が
成立しなくなるので、専用の AI を書かずに「延々と旋回し続ける機体」になる。
そこへ `orbitR` / `orbitAlt` を正弦で揺らして寄り引きを作っている。

抜けるときは P → ABORT MISSION（このモードは自然には終わらない）。

## 敵の紙飛行機

**低空帯（220〜1000m）**は回避しながら陣地へ突っ込んで投弾し、離脱する。
**高空帯（1200〜1900m）**は回避機動をとらず、高度を保ったまま自陣上空を
まっすぐ突っ切って通過ぎわに投弾する。

| | DART | LANCE | WEDGE | CRANE | CONDOR |
|---|---|---|---|---|---|
| 帯 | 低空 | 低空 | 低空 | **高空** | **高空** |
| 巡航 | 320 km/h | **400 km/h** | 260 km/h | 300 km/h | 250 km/h |
| 突入 | 350 km/h | **450 km/h** | 280 km/h | — | — |
| 旋回率 | 30 °/s | **14 °/s** | 18 °/s | 5 °/s | 3 °/s |
| 蛇行 | 1.0 | 0.25 | 0.7 | **無し** | **無し** |
| HP | 45 | 70 | 130 | 260 | **480** |
| 翼幅 | 6m | 5m | 11m | 22m | **32m** |
| 当たり判定 | 3.4m | 2.6m | 5.0m | 8.0m | **11m** |
| 陣地への打撃 | 7 | 9 | 20 | 20 | **32** |
| 得点 | 100 | 130 | 200 | 380 | **700** |
| コスト | 10 | 18 | 26 | 55 | 95 |
| 解禁 | WAVE 1 | WAVE 2 | WAVE 3 | **WAVE 5** | **WAVE 8** |

- **LANCE** は速いが旋回半径が大きい（125 m/s・14°/s で約 500m）。
  一度陣地を外すと立て直しに時間が掛かるので、置き撃ちが効く相手
- **CRANE** は折り鶴、**CONDOR** はアンデスコンドル折り。どちらも実際の
  折り紙の形をワイヤーフレームに起こしてある

### 高空帯の上限を 1900m にした理由

20mm の自爆信管（5.5 秒）が**斜距離 2500m 前後で働く**ため、それ以上に
上げると米英独の 20mm が一発も届かなくなる。各砲の届く斜距離は:

| | 20〜30mm | 重対空砲 |
|---|---|---|
| USA | 2479m | 40mm ボフォース 5182m |
| JAPAN | 25mm 4000m | 75mm 5912m |
| GERMANY | 2556m | 88mm 6576m |
| BRITAIN | 2470m | ポンポン砲 3315m |
| USSR | 25mm 4044m | 37mm 4289m |

高度 1900m なら、20mm でも水平 3160〜3420m ぶんの迎撃窓が残る。CONDOR の
速度（69 m/s）で **46 秒**。実測では射撃解に完全追従した場合、20mm だけで
35〜41 秒、重対空砲なら 9〜22 秒で CONDOR を落とせる（投弾前に間に合う）。

**重対空砲を持つ日独が明確に有利**で、40mm 級しか無い米英ソは 20mm と
併用してぎりぎり間に合わせることになる。国選択がそのまま難易度になる。

## WAVE — 敵側の予算

敵に予算を与えて、その範囲で編成を買わせている。

```
予算 = 20 + 17×(n-1) + 0.9×n²
高空に回す割合 = WAVE 5 から 42%、+2%/wave、55% で頭打ち
重み = コスト^bias（bias は 0.25 → 1.7 まで WAVE とともに上昇）
```

bias が上がるほど「高いものを 1 機」に寄るので、予算が同じでも後半ほど
編成が重くなる。**財布を低空と高空で分けている**のが肝で、1 つにすると
「爆撃機 2 機だけのウェーブ」が普通に出て低空の砲が完全に暇になる。

安全装置が 3 つ:

- **高空機が解禁されたウェーブ以降は、いちばん安い爆撃機を 1 機だけ
  予算を無視して確保する**。WAVE 5 時点の高空予算は 47 しかなく、双発が
  55 なので、素直に買わせると初登場の次から数ウェーブ上空が空になる
- **解禁されたそのウェーブだけは、その新型も 1 機確保する**（初登場を
  はっきり見せるため。WAVE 8 で必ず CONDOR が 1 機来る）
- **低空機が 2 機を切ったら DART で埋める**

同時出現は 10 機まで。実際に出る編成（40 回平均）:

```
W 1 予算  21  2.0DA
W 3 予算  62  1.2DA + 1.0LA + 1.1WE
W 5 予算 111  1.1DA + 1.0LA + 1.3WE + 1.0CR   ← 双発が初登場
W 8 予算 197  1.9DA + 1.6LA + 2.0WE + 1.0CR + 1.0CO   ← 四発が初登場
W12 予算 337  1.2DA + 2.5LA + 4.0WE + 1.5CR + 0.8CO
W18 予算 601  0.8DA + 2.2LA + 3.0WE + 2.3CR + 1.7CO
```

## PRISM — 虹色の褒賞機

数ウェーブに 1 度、予算とは別枠で虹色に光る紙飛行機が湧く。

- **撃ち落とすと陣地の耐久が +25%**
- 攻撃してこない。**25 秒で帰ってしまう**ので、見つけたらそちらを優先する判断が要る
- 低空 500〜800m、蛇行は DART より激しい
- 出現率は耐久しだい（60% 以上なら 25%、60% 未満で 45%、**30% 未満で 75%**）。
  詰みだけは避けたいので、追い込まれているほど出やすい

色は EGA 16 色を毎フレーム巡回させているだけ（新しい描画は足していない）。
時間で自動回復させる案もあったが、それだと上手い人にも下手な人にも同じだけ
配ることになって緊張が抜けるので、**取りに行く回復**にしてある。
ウェーブ突破ごとの +8 はそのまま残してある。

## 兵装

**5 カ国から 1 セットを選ぶ。** どの国も 6〜8mm / 12〜15mm / 20〜30mm / 重対空砲
の 4 門構成で、諸元は実在の砲の公表値。

| | 6〜8mm | 12〜15mm | 20〜30mm | 重対空砲 |
|---|---|---|---|---|
| **USA** | M1919A4 連装 | M2HB M45 4連装 | Oerlikon Mk24 連装 | 40mm Bofors L/60 連装 |
| **JAPAN** | 九二式 7.7mm 連装 | 九三式 13mm 連装 | 九六式 25mm 三連装 | 八八式 7.5cm 高射砲 |
| **GERMANY** | MG34 Zwillingssockel 連装 | MG151/15 Drilling 3連装 | 2cm Flakvierling 38 | 8.8cm Flak 36 |
| **BRITAIN** | Vickers .303 4連装 | Vickers .5 Mk III 4連装 | 20mm Polsten 連装 | QF 2pdr ポンポン砲 4連装 |
| **USSR** | 4M マキシム 4連装 | DShK 連装 | 72-K 25mm 連装 | 61-K 37mm 連装 |

**連装にできるものは全て連装以上にしてある。** 例外は日独の高射砲だけで、
八八式 7.5cm も 8.8cm Flak 36 も実在の連装型が無いため単装のまま。

砲身の並びも実物に合わせてある。**M45 / Vickers 4連装 / Flakvierling /
ポンポン砲は 2x2 の二段**、**MG151 Drilling は上1・下2 の三角**、
**4M マキシム（GAZ-AAA 搭載のあれ）と九六式25mm三連装は横一列**。

初速・弾丸質量・発射速度・装弾数・砲身数は実物どおり。**再装填時間・旋回速度・
威力・過熱はゲーム側で決めた値**（実物の装填時間は隊の練度でしか決まらないし、
旋回速度は砲そのものではなく砲架の駆動の話なので、口径が上がるほど鈍る勾配を優先した）。

### 国ごとの性格

- **USA** — 手数。弾が尽きない。M45 は 800発、M1919 は 500発持つ
- **JAPAN** — 弾倉が小さい。九三式13mm は 30発箱×2 で 4 秒、九六式25mm は
  15発箱×3 で 4.1 秒。**弾切れが過熱より先に来る唯一の国**。代わりに
  九六式25mm は自爆信管が 9.7 秒（4000m）まで伸びていて、いちばん遠くへ届く機関砲
- **GERMANY** — MG151/15 の初速 960 m/s でリード量が明確に小さい。
  Flakvierling は 1800発/分（20mm 級で最大）だが 2.4 秒で過熱する
- **BRITAIN** — 4連装が 3 つ。撃ち続けられるが 1 発は軽い
- **USSR** — クリップ給弾。72-K と 61-K は**装填時間が 0.3 秒**しかなく、
  実質リロードが無い。代わりに 6 クリップ撃つと過熱して止まる

### 過熱の決め方

`heatPerShot` は連射可能秒数から逆算している。

```
heatPerShot = (100 / 連射可能秒数 + 0.45 * coolRate) / 毎秒発射数
```

6〜8mm は 5.5 秒、12〜15mm は 2.7 秒、20〜30mm は 2.4 秒で揃えてある。
九六式25mm だけ 6.0 秒に緩めてあるのは、**弾切れ（4.1 秒）を先に来させたい**ため。
ソ連の 2 門は「6 クリップ撃ち切りで過熱」から逆算した値（72-K が 42発/5.3秒、
61-K が 30発/5.6秒）。

装弾数が多いので、実際に連射を止めるのは弾切れではなく**過熱**。
これは実物の対空機銃と同じで、砲身が焼ける前に指を離す判断が要る。
20mm は突っ込んでくる機体には追従できない。早めに置いて待つしかない。

### 望遠の倍率

右ボタン / Z で覗いているあいだ、**ホイールと W / S で倍率を x2〜x8 まで
0.5 刻みで変えられる**（そのあいだホイールでの兵装切り替えは効かない）。
倍率は撃ち方の癖そのものなので、覗くのをやめても覚えたままにしてある —
次に覗いたとき前回の倍率で始まる。画角は `52 / 倍率` で作っていて、
既定の x2.5 が以前の固定値（画角 21 度）とほぼ同じ見え方になる。

照準環はミルで定義してあるので、倍率を上げると環も一緒に拡大される。
画面の目盛りは倍率に関係なく常に実角度と一致する。

### 見越し点の表示距離

OPTIONS の `LEAD AID RANGE` で **1.0〜3.0km を 0.1km 刻み**で変えられる。
既定は 2.0km。遠くまで出すほど楽になるので、「どこまで補助を効かせるか」を
撃つ側が決められるようにしてある。HARD では設定に関わらず出ない。

### 機体が画面外にいるときの見越し点

倍率を上げるほど画角が狭くなるので（x8 で 6.5 度）、**「撃つべき点は見えて
いるのに機体は視界の外」がふつうに起きる**。ここで見越し点ごと消してしまうと、
望遠がいちばん要る場面で照準補助が無くなってしまう。

そこで、機体が画面の外でも**見越し点が画面の中にあるなら □ を出し、
そこから機体のいる方向へ破線を伸ばして視界の縁で切る**。

```
|  照準拡大画面   □- - - -|- - - - ✈  画面外  |
```

並びは画面内のときと同じ `✈ - - - - □` のままで、✈ の側が画面の外に
出ているだけ、という見え方になる。実測では x8・目標 941m・角度差 4.74 度
（半画角 3.25 度）で、機体が画面外 x=-134 のときに見越し点が中央に出る。

見越し点も画面の外へ出てしまったときは何も描かない（縁のロック矢印だけが残る）。
HARD と、設定した表示距離より遠い目標では出ないのは画面内のときと同じ。

### ロック目標の画面外表示

**ロックした目標が画面から出ても、視界の縁に矢印と距離が出る。** 真後ろに
回り込まれても消えない。透視投影はニアプレーンより手前の点を返せないので、
位置ではなく「砲軸から見た角度差」から向きを作っている。

自動追尾で拾っているだけの目標は縁に出さない（視界の外の情報で画面が
埋まってしまうため）。出るのは Tab で固定した 1 機だけ。

### バックグラウンド装填

**マガジンを撃ち切って始まった装填は、他の砲に持ち替えても裏で進む。**
弾切れ → 別の砲で撃つ → 戻ったら装填が終わっている、という流れになる。
装填中の砲は計器盤下段の兵装タブが黄色く光り、終わると `... RELOADED` が出る。

残弾があるうちに R で入れ直したぶんは裏で進まない（`Gun.bgReload` は
`startReload()` の時点で `ammo <= 0` だったときにだけ立つ）。これを区別しないと
「弾が減ったら全部の砲を順に叩いておく」のが最適手になってしまうため。

構えていない砲の**冷却は常に進む**。過熱したら持ち替えて冷ます、が成立する。

### 目標のロック（Tab）

複数機が近い角度に重なると、砲軸にいちばん近い機体を拾う自動追尾が細かく
乗り換えて、見越し点が激しく往復する。それを止めるための手動指定。

- 機体をレティクルの中央付近（画角に比例した円錐、広角でおよそ 6°）に入れて Tab → ロック
- ロック中は砲をどこへ向けても目標が動かない。照準環の上に `- LOCK -`、目標枠が黄→白になる
- 何もない空で Tab → 解除して自動追尾へ戻る
- ロックした機体が撃墜・離脱したら黙って自動追尾に戻る

自動追尾のほうにも、乗り換え直後 0.5 秒は動かさない粘り（`targetHold`）を入れて、
ロックしていない状態でのちらつき自体を減らしてある。

### 時限信管の砲

40mm ボフォース（USA）、八八式 7.5cm（JAPAN）、8.8cm Flak 36（GERMANY）が
時限信管を積んでいる。
指定目標への弾着時間がそのまま信管秒時になる（計器盤に `FUZE` と `BURST` として出る）。
つまり**信管は正しい距離で炸裂するが、炸裂する場所は砲身の向いた先**。
方位と仰角は自分で当てる必要がある。目標を指定していないと信管が設定されず、
`FUZE UNSET` と出て炸裂しない弾になる。

高射砲（八八式・8.8cm Flak）は 4 秒に 1 発しか撃てない代わりに、
信管誤差が 0.8%（機関砲の 1.4% の半分強）で炸裂半径も 25〜30m ある。
遠距離で当てにいく砲はこの 2 つだけ。8.8cm は 6000m でも弾着 10.5 秒で届く。

以下はボフォースの話。機械式信管なので秒時に 1.4% の誤差が乗る。近距離（1000m・飛翔 1.3s）だと
誤差の全幅で 25m ほどだが、4000m（飛翔 7.9s）まで伸ばすと 70m 近くまで広がる。
炸裂半径は 14m しかないので、そこまで行くとまず当たらない。史実でも近接信管
（VT信管）が出るまでの 40mm ボフォースは遠距離だとほとんど当たらなかった —
その弱さも込みで再現している。近距離で手数を出す砲、と割り切るのが正しい。

## 弾道について

弾は瞬間的には届かない。運動方程式は

```
dv/dt = -k * rho(h) * |v| * v  -  g        k = 0.5 * Cd * A / m
```

の二乗抗力で、空気密度は `rho(h) = exp(-h/8500)` の指数大気。
`data/guns.json` の口径・弾丸質量・抗力係数からそのまま `k` が決まる。

この式が出す弾速の距離減衰は実測値とほぼ一致する:

| | 300m | 500m | 1000m |
|---|---|---|---|
| 7.7mm (.303 Mk VII) | 597 m/s | 515 m/s | 357 m/s |
| 12.7mm (.50 BMG) | 771 m/s | 703 m/s | 557 m/s |
| 15mm MG151 | 813 m/s | 728 m/s | 552 m/s |
| 20mm エリコン | 728 m/s | 665 m/s | 530 m/s |
| 25mm 九六式 | 810 m/s | 756 m/s | 634 m/s |
| 37mm 61-K | 814 m/s | 772 m/s | 677 m/s |
| 40mm ボフォース | 818 m/s | 778 m/s | 687 m/s |
| 75mm 八八式 | 694 m/s | 678 m/s | 638 m/s |
| 88mm Flak 36 | 792 m/s | 774 m/s | 731 m/s |

40mm ボフォースは口径のわりに弾が重い（0.9kg）ぶん断面密度が高く、
抗力係数 `k` は 12.7mm や 20mm よりむしろ小さい（弾頭が大きくなるほど、
面積は半径の2乗でしか増えないのに質量は3乗で増えるため）。
だから 2000m でもまだ 527 m/s、弾着 3.0 秒しか掛からない。
4000m まで伸ばしても 316 m/s・弾着 7.9 秒までは飛ぶ。射程だけ見れば
このゲームでいちばん遠くまで届く砲になった。ただし前述のとおり、
その距離だと信管誤差が響いて当たらなくなる。

つまり必要なリード量も実物どおりになる。1000m の目標に 12.7mm を当てるには
弾着まで約 1.5 秒。秒速 90m で横切る機体なら 130m 以上先に撃つ必要がある。

計器盤の TOF（弾着時間）と LEAD（必要リード量）は、この抗力モデルを反転させた
解析解を反復して出している。照準環の目盛りはミル（mrad）で、焦点距離から逆算して
描いているので望遠にすると環も一緒に拡大する。つまり画面の目盛りは常に実角度と一致する。

落下量は真空の `0.5*g*t²` ではなく、鉛直方向にも抗力が効く前提の
`(g/c)(t - (1-e^{-ct})/c)`（`c = k*rho*v̄`）を使っている。
これを入れないと 7.7mm で 1200m 先を撃つと 8m 以上上に外れる。

さらにこの解析解を**実弾道で検算して詰めている**（`refineIntercept`）。
解析解は重力で増えた鉛直速度ぶんの抗力増加を見ていないので、飛翔時間が
5 秒を超えると弾が手前に落ちる。4000m で 40m ほど。時限信管の砲（40mm
ボフォース）の信管秒時はこの時間をそのまま使うので、そのままだと炸裂位置
そのものがずれる。そこで出した方向へ実際に弾を飛ばし、最接近時のずれを
照準点に足し戻す（ニュートン法 1 ステップ相当を 2 回）。1 ステップ内は
弾も目標も直線運動とみなして最接近時刻を解析的に求めるので、ステップ幅
による量子化も起きない。

検算後の実測（高度 400m を秒速 90m で真横に横切る標的に対し、散布界と初速
ばらつきを 0 にして射撃解の方向へ 1 発だけ撃ち、実際の当たり判定を見たもの）。
USA の兵装セットで測ったもので、他国の砲も口径が近ければ同じ傾向になる:

| | 600m | 1200m | 2000m | 3000m | 4000m |
|---|---|---|---|---|---|
| 7.7mm | 命中 | 命中 | 命中 | 外れ | 外れ |
| 12.7mm | 命中 | 命中 | 命中 | 命中 | 外れ |
| 20mm | 命中 | 命中 | 命中 | 外れ | 外れ |
| 40mm ボフォース | 命中 | 命中 | 命中 | 命中 | 命中 |

外れているのはソルバの誤差ではなく、**弾がそもそも届いていない**ケース。
7.7mm の 3000m は落下して地面に刺さる。20mm の 3000m は自爆信管（5.5秒）が
着弾前に働いて空中で炸裂する。

40mm ボフォースが全域で命中しているのは検算のおかげ。ただしこれは
「弾道ソルバの精度」の検証であって、実戦での命中率とは別の話 —
上で書いたとおり信管誤差を戻すと 4000m はまず当たらない。

射撃解の計算は 30Hz に間引いてある（物理は 200Hz）。目標は滑らかに動くので
表示にも命中にも影響しない。

## 砲架の追従

既定では砲架に旋回速度の上限がある（オプションで DIRECT に切替可）。
マウスが動かすのは「指令方向」で、砲身はそこへ最大角速度で追いつこうとする。
灰色の十字が指令方向、照準環が実際の砲身の向き。ズレが 3°を超えると十字が赤くなる。

目標のリードに加えて砲架のリードも要る、というのがこのモードの狙い。

## 実装メモ

- **描画は canvas 2D API を使わない。** 線がアンチエイリアスされるため。
  ImageData を直接叩いて Bresenham で 1px の線を引き、文字も同じ
  フレームバッファに打つ。3D の線と HUD の文字が同じ画素グリッドに乗る。
- **表示は整数倍のみ**（ウィンドウ内は x1〜x3、フルスクリーンは自動で x6 まで）。
  `image-rendering: pixelated`。
- **物理は 200Hz 固定ステップ。** 弾速 900m/s でも 1 ステップ 4.5m しか進まないので
  線分と球の判定で薄い機体を貫通しない。描画は rAF まかせ。
- **フォントは内蔵の 6x8 ビットマップ。** TenoText8x8 を使っていないのは、
  ここが DOM ではなくフレームバッファで、OTF を読むとラスタライズで
  補間が入るため。必要なら TenoText8x8 を 8px でオフスクリーンに焼いて
  2値化し、このフォントテーブルを差し替えられる。
- **16 色しかないのでグラデーションは全部ディザ。** 空は地平線からの距離で
  バンドを作り、境目を 4x4 の Bayer 行列で繋いでいる。
- 撃墜時の破片は機体メッシュの稜線をそのまま飛ばしている。破片用のモデルはない。
- **高空の爆撃機は状態機械に分岐を足さずに実現している。** `OVERFLY` を
  1 つ足しただけで、`ORBIT` や `ATTACK` には一切触っていない。投弾は
  「陣地までの距離が増えに転じた瞬間」＝最接近で 1 回だけ拾う。真上を通る
  針路で進入させてあるので、`R < 130` のような閾値より確実に取れる。
  FREE RANGE の的（`passive`）だけは爆撃機でも `OVERFLY` に入れず、
  その場で旋回させている（通過して消えてしまうと的にならないため）。
- **PRISM も同じ手で作ってある。** `maxRuns` を 0 にすると `ORBIT` から
  `ATTACK` への遷移条件（`runs < maxRuns`）が成立しなくなるので、
  専用の AI を書かずに「攻撃してこない機体」になる。FREE RANGE の
  `passive` とまったく同じ仕掛け。
- **低空の投弾判定は「陣地から 150m 以内」だけ。** 以前は
  「150m 以内 **または** 高度 40m 未満」にしていたが、降下の目標高度が
  25m なので、**陣地を大きく外したまま降りただけで投弾が成立していた**
  （旋回半径の大きい LANCE で顕著）。いまは距離だけで判定し、届かなかった
  進入は投弾させずに立て直させる。失敗した進入は攻撃回数（`runs`）に
  数えず `attempts` で別に数える — 数えてしまうと外し続けただけで
  帰ってしまうため。打ち切りは「最接近から 1.6 倍 + 250m 離れたら」。
  1 フレームでも遠ざかったら打ち切る作りにすると、旋回中に離れる区間だけで
  失敗扱いになる。
- **砲身の並びは `mount` で持つ**（`row` / `square` / `triangle` / `single`）。
  M45・Vickers 4連装・Flakvierling・ポンポン砲は実物どおり 2x2 の四角、
  MG151 の Drilling は上1・下2 の三角、4M マキシムと九六式25mm三連装は横一列。
  弾道側（`guns.js` の `barrelLayout`）と描画側（`hud.js` の `barrelSet`）が
  同じ順序で同じ配置を返すので、銃口炎は実際に撃った砲身の位置に出る。
- **根元の開き具合（`MOUNT_FAN`）は並びごとに変える。** 砲身の根元は
  `根元X = 銃口X * FAN` で置いているので、**FAN が同じだと全砲身の中心線が
  画面中央の一点に集まる**。横一列（2.7）はその一点へ集まっていても横方向に
  しか広がらないので気にならない — 元の 4 連装の絵がまさにこれだった。
  一方 2x2 や三角は上下の段が同じ点へ吸い込まれて「1 つの基点から全部
  生えている」ように見えるので、扇を 1.45 まで弱めて段ごとに自分の根元を
  持たせてある。上段は下段の真上ではなく半歩外へずらし、下段より短く切って
  いる（真後ろから見上げる絵なので、上段の付け根が下段の陰に入るのが正しい）。
- マズルブレーキの有無は砲身の太さではなく**口径**で決める（40mm 以上）。
  上段の砲身だけ 1px 細く描いているので、太さで判定すると同じ砲なのに
  下段にだけブレーキが付いてしまう。
- **発砲音は口径のアンカー補間で作る**（`audio.js` の `shotParams`）。
  7.7 / 12.7 / 20 / 40mm の 4 プリセットはそのまま節点として残してあり、
  その口径の砲では以前と 1 サンプルも変わらない音が出る。88mm 用の `heavy` を
  1 つ足して、間の口径（13.2 / 15 / 25 / 37 / 75mm）は `log(口径)` 上で補間する。
  減衰だけは口径では決まらないので、「何発ぶんまで重なってよいか」も同じ
  アンカー表にして `decay <= 許容重なり数 x 発射間隔` で頭打ちにしている。
  ボフォースが単装（0.5秒間隔）から連装（0.25秒間隔）になったとき、
  減衰が自動で 0.34 → 0.17 に詰まるのはこの規則。
  砲ごとに `sound` を書けばプリセット名で上書きもできる。
- **起動画面は 2 画面ぶん。** 実機と同じで、BIOS の POST が流れたあと
  画面が消えて DOS が起動する（`makePostLines` / `makeLoadLines`）。
  ESC でいつでも最後まで飛ばせる。

  1 画面目は 1997 年の 486 機として辻褄が合う値にしてある。とくに
  **486DX2 に 80487 を積むとは書けない** — 80487 は FPU を持たない
  486SX 用の石で、DX / DX2 は FPU を内蔵しているため。メモリも
  640K + 7168K + UMA 384K = ちょうど 8192K になる組にしてある
  （640K + 8192K だと合計が中途半端な 8.6MB になってしまう）。
  ほかの番地も当時の標準どおり: シリアル 3F8/2F8、パラレル 378、
  サウンドが PORT 220 / IRQ 5 / DMA 1、IDE 540MB の CHS 1050/16/63
  （= 541.9MB）。最後に Award BIOS 風の ID 文字列を置いてある。

  2 画面目の `FLAKALT.EXE` から下は `data/guns.json` の国数・砲数と
  `aircraft.js` の `TYPES` をその場で数えて出しているので、
  国や機種を追加・削除すればここの行数もそのまま変わる。装飾ではなく
  弾道定数と同じ扱い。表示は 3 段:
  `MOUNTING WEAPON DATABASE`（国と砲セット数）→
  `LOADING BALLISTIC TABLES`（選んでいる国の実弾道。国は MISSION SETUP の
  選択がそのまま出る）→ `LOADING CONTACT DATABASE`（紙飛行機 5 種 + PRISM、
  高度帯と解禁 WAVE 付き）。
